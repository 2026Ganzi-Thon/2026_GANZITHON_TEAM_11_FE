# 양 세는 밤

고민을 적고 정한 수만큼 양을 세며 하루를 마무리하는 Android 앱입니다.

2026 간지톤 11팀 프론트엔드 저장소입니다.

## 주요 흐름

- **밤:** 고민 입력 → 필요 시 도움 안내 → 양 수 선택 → 글·노래 카드 보기 → 밤 마무리
- **아침:** 양 데려오기 → 어젯밤 돌아보기 → 양떼·양 상세 확인
- **카드:** 글·노래 작성, 내 카드 관리, 솜털 표시, 털실 보내기, 노래 담기
- **설정:** 고민 기록·삭제, 생년월일 변경, 운세, 알림 희망 설정

현재는 **개발용 mock 시연 중심**입니다. 실제 서버·인증·영속 저장·곡 검색 API·음원 재생은 연결하지 않았으며, 시연 데이터는 메모리에서 관리하고 시연 종료·앱 재실행 시 초기화합니다. 전화·연락처·브라우저 열기와 클립보드 등 일부 기기 기능은 실제로 동작합니다.

## 개발 환경

- Expo SDK 58 · React Native · TypeScript · Expo Router
- Node.js **24.15.0** (`.nvmrc`) · npm **11.12.1**
- Android Studio · Android SDK · JDK **21**
- Android 에뮬레이터 또는 USB 디버깅을 활성화한 Android 기기

## 실행

```sh
npm ci
npm run android
```

첫 실행은 Android 개발용 앱을 빌드·설치하고 Metro를 시작합니다. 개발용 앱이 이미 설치되어 있다면 `npm start`로 Metro만 실행할 수 있습니다.

## Android 테스트 체험판

체험판 APK는 Metro 없이 실행되며 기존 개발 앱과 함께 설치할 수 있습니다. 앱 이름은 **양 세는 밤 · 체험판**, 패키지는 `com.ganzithon.yangsebam.preview`입니다. 시작 화면에서 밤→아침 시연과 가입→첫 홈을 선택합니다. 계정·기록은 mock이며 앱 재실행 시 초기화됩니다. 기기 알림과 외부 앱 열기는 실제로 동작합니다.

로컬 빌드는 Android SDK·Build Tools 37·JDK 21과 저장소 밖의 전용 PKCS12 서명 키가 필요합니다. 키 저장소와 개인 키는 같은 비밀번호를 사용합니다. 다음 환경 변수를 설정한 뒤 실행합니다. 키와 비밀번호는 커밋·공유 파일에 넣지 않습니다.

- `ANDROID_HOME`: Android SDK 경로
- `JAVA_HOME`: JDK 21 경로
- `PREVIEW_KEYSTORE_FILE`: 체험판 서명 키 경로
- `PREVIEW_PASSWORD_FILE`: 키 비밀번호 한 줄을 담은 비공개 파일 경로
- `PREVIEW_KEY_ALIAS`: 기본값 `yangsebam-preview`

```sh
npm run build:preview:android
```

이 명령은 `android/`를 재생성하므로 생성 폴더의 수동 변경을 먼저 보존합니다. 결과 APK와 SHA-256은 `dist/preview/`에 생성합니다. 후속 업데이트에도 같은 서명 키를 사용하고 `versionCode`를 올립니다. EAS 계정을 연결한 환경에서는 `eas.json`의 `preview` 프로필도 사용할 수 있습니다.

체험판을 만든 뒤 개발 빌드를 다시 만들 때는 생성된 네이티브 설정도 기본 모드로 되돌립니다. `npm run android`만 실행하면 이전 체험판 설정을 재사용할 수 있습니다.

```sh
APP_VARIANT=production npx expo prebuild --clean --platform android
APP_VARIANT=production npm run android
```

`APP_VARIANT=preview`는 체험판 전용입니다. 기본값 `production`에서는 mock 진입을 허용하지 않습니다. 체험판은 스토어 출시 빌드와 분리합니다.

## 환경 변수

API 연동 시 `.env.example`을 `.env`로 복사하고 `EXPO_PUBLIC_API_BASE_URL`에 `/api/v1`을 포함한 서버 주소를 지정합니다. 현재 mock 시연에는 실제 서버가 필요하지 않습니다.

`EXPO_PUBLIC_*` 값은 앱 번들에 포함되므로 비밀 키를 넣지 않습니다. 토큰·입력 원문·민감한 서버 오류도 로그나 공개 파일에 남기지 않습니다.

## 개발용 미리보기

개발 빌드의 시작 화면에서 기능별 미리보기를 엽니다. `/dev/*` 경로는 일반 배포 빌드에서 차단하며, 별도 패키지의 테스트 체험판에서만 허용합니다.

| 대표 경로                 | 확인할 흐름                                       |
| ------------------------- | ------------------------------------------------- |
| `/dev/home-night-morning` | 첫 홈·밤 세기·아침 채택·회고·고민 목록 공유       |
| `/dev/night-morning`      | 밤 입력부터 양 세기·아침 채택·회고까지 연결 시연  |
| `/dev/signup-home`        | 가입·기기 알림·첫 홈·같은 계정의 밤과 아침        |
| `/dev/signup`             | 가입 시작·이메일·동의·필수 생일 입력              |
| `/dev/my-cards`           | 내 카드 목록·작성·삭제·반려 글 재제출             |
| `/dev/settings`           | 설정·고민 선택 삭제·생년월일·알림 희망 설정       |
| `/dev/card-support`       | 작성 중 도움 안내·기기 앱 열기·초안 복귀          |
| `/dev/android-reminder`   | Android 알림 권한·로컬 예약·취소                  |
| `/dev/night-entry`        | 고민 응답별 분기·밤 도움 안내·계속하기·양 수 선택 |
| `/dev/night-reentry`      | 밤 상태 재조회·도움 안내·기존 세션 이어 세기      |
| `/dev/first-night-home`   | 첫 밤 전 홈·21시/04시 버튼 전환·밤 입력 진입      |

로그인·피드·양 상세·운세 등 개별 화면과 오류·재시도 예시는 각 미리보기에서 확인합니다.

고민 목록의 선택 삭제는 고민 글과 돌아보기 답을 함께 지우며 양·카드·털 색은 유지합니다. 일부 실패·미확인 결과 복구는 mock으로 확인하며, 실제 일괄 삭제 API는 연결하지 않았습니다. 양 상세의 단건 삭제는 기존처럼 고민 원문만 지웁니다.

가입 온보딩은 예시 약관과 메모리 mock으로 검증합니다. 실제 인증·토큰·약관 원문·추가 동의 항목의 서버 저장은 연결하지 않았으며 `/dev/signup-home`에서 알림 시간(15분 단위)·허용/나중에·낮 가입 안내·첫 밤 전 홈을 연결합니다. 가입 생일과 알림 설정은 같은 홈·설정에 반영하며 낮 안내는 같은 시연 계정에서 한 번만 표시합니다. 밤 가입은 안내를 건너뜁니다. 첫 홈부터 밤 세기·아침 채택·회고·내 카드까지 같은 계정과 기록을 공유합니다. 메뉴의 시간 이동은 같은 계정으로 당일 21시와 다음 날 04시를 확인하며, 이전 시각으로 되돌리지 않습니다. 앱 종료 후 복원은 지원하지 않습니다.

Android 알림 연결은 계정 설정만 mock이며 기기 권한·로컬 예약은 실제로 동작합니다. 프로세스 재실행 시 설정이 초기화되고 이전 시연 예약을 정리합니다. 정시 배달은 보장하지 않습니다.

밤 도움 안내는 입력 내용과 무관한 고정 mock입니다. 안내 누락은 다시 불러오며, 계속하기가 확인된 뒤에만 양 수 선택으로 이동합니다. 실패·취소 후 고민을 유지하며, 기존 세션 복귀는 아래 재진입 미리보기에서 확인합니다.

밤 재진입 미리보기는 명시적 상태 조회로 기존 세션과 마지막 위치를 이어 봅니다. 기록은 해당 mock 시연 안에서만 유지합니다. 실제 앱 종료 후 복원·오프라인 저장·자동 재진입 판단과 낮·마무리 복귀는 연결하지 않았습니다.

첫 밤 전 홈은 조회에 성공한 센 밤 수가 0일 때 표시합니다. 하단 버튼은 mock 서버 시각으로 낮(04~21시)에 비활성화하며, 밤 진입 전 다시 확인합니다. 운세는 고정 예시이고 밤 입력은 독립 시연입니다. 첫 밤 완료 후 계정 갱신·기존 세션 복귀·월 선택·꾸미기는 연결하지 않았습니다.

홈·밤·아침 통합은 한 예시 계정의 첫 밤을 공유합니다. 홈 왕복 시 피드 위치와 마무리 상태를 유지하고 다음 아침의 양·회고·고민 목록 및 삭제를 같은 기록에 반영합니다. 밤·아침에서 맡긴 글·노래는 같은 내 카드 목록에 검수 중으로 표시하며, 접수 재확인·삭제·반려 글 재제출도 같은 목록에 반영합니다. 시연용 시간 이동은 다음 아침 한 번만 적용합니다. 기존 밤 재조회 미리보기의 bootstrap/resume·여러 밤·앱 종료 후 복원은 후속입니다.

## 프로젝트 구조

```text
src/app/       Expo Router 경로·레이아웃·개발용 진입점
src/features/  기능별 화면·상태·테스트
src/api/       HTTP 클라이언트·오류·API 타입
src/mocks/     mock 응답·시연 데이터
src/ui/        공통 UI·테마
assets/        이미지·로컬 에셋
app.json       앱·네이티브 설정
.github/       CI·PR 템플릿
```

## 검사

```sh
npm run check          # 타입·ESLint·Prettier 검사
npm run test:ci        # Jest 테스트
npm run bundle:android # Android JavaScript 번들
```

PR에서 GitHub Actions로 위 검사를 실행합니다. 변경한 화면은 Android에서도 확인하고 PR에 검증 결과와 남은 제한을 기록합니다. 자동 검사와 번들은 실제 기기·서버 연동 검증을 대신하지 않습니다.

코드 포맷 적용은 `npm run format`을 사용합니다. 기존 의존성 보안 경고는 [#3](https://github.com/2026Ganzi-Thon/2026_GANZITHON_TEAM_11_FE/issues/3)에서 추적합니다.
