# 앱 폰트

- **PF Stardust·PF Stardust Bold(3.0)**: 피나타, [원 배포·이용 조건](https://blog.naver.com/campanula913/221366697603). 원본 기본체·Bold를 수정하지 않고 앱에 탑재하며 폰트 파일을 공개 저장소에 재배포하지 않습니다.
- **Ownglyph PDH(온글잎 박다현체)**: 보이저엑스·해당 손글씨 제공자, [원 배포·이용 조건](https://www.ownglyph.com/trial/11ebf7f8-0997-4f03-a393-0959a07286aa). 원본을 수정하지 않고 앱에 탑재합니다.

`node scripts/fetch-fonts.mjs`로 원 배포처의 원본 TTF를 준비합니다. 파일은 Git에서 제외된 `.expo/app-fonts/`에 준비합니다. 다운로드 파일은 SHA-256으로 확인하며 Git에서 제외합니다. CI와 로컬 체험판 빌드에서도 같은 명령을 실행합니다. EAS 빌드 전에도 이 명령으로 파일을 준비하며 `.easignore`를 통해 빌드 아카이브에만 포함합니다. 폰트는 JS 자산으로 묶어 첫 실행·오프라인에서도 로드하며, 네이티브 폰트 설정은 변경하지 않습니다.

PF 폰트의 첨부 다운로드 주소는 원 배포 페이지에서 파일명으로 매번 확인합니다. 네트워크·403·일시적 서버 오류는 최대3회 재시도하며, 재시도 시 첨부 주소를 다시 얻습니다. 원본 SHA-256이 달라지면 중단합니다. 검증 완료한 파일만 저장하며 CI 캐시는 폰트 명세가 바뀌면 분리됩니다.
