# 실제 API 연동 확인

확인일: 2026-11-20 · AWS `https://54.252.207.11/api/v1` · 재배포 후 확인.

## 확인한 동작

- 임시 계정 가입·동의·생일, 홈·설정, 계정 삭제. 이전 확인에서는 토큰 갱신·로그아웃·재로그인과 글/직접 입력 노래 접수·목록·삭제도 통과했습니다.
- 실제 밤 시각에 고민 저장 → 3마리 세션 생성 `201` → 피드 조회·세션 재개·진행 저장 → 털실/솜털 반응 `200` → 마무리 `200` → 마무리 확인 `204` → 아침 작성 선택 `200`을 확인했습니다.
- 운세 `200`, 스티커 7종 `200`, 실제 곡 검색 20건 `200`을 확인했습니다. 이전의 빈 카탈로그·운세 503은 해소됐습니다.
- 낮에는 밤 기록 쓰기를 제한하는 정책을 유지합니다. 운영 서버의 시간·DB를 변경하지 않았습니다.

검증 계정은 삭제했습니다. 인증 비밀값은 로그와 저장소에 남기지 않습니다.

API 포트의 이전 기본 실패 구현은 최신 백엔드 소스에서 교체됐고, 배포 서버에서도 세션 생성·피드·마무리가 동작합니다. 스티커 원격 이미지와 저장 연결은 프론트 HTTP fixture로 검증하며, 실제 양을 얻기 전 운영 저장 성공으로 간주하지 않습니다.
